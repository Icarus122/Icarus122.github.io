 给王振华的情书 —— 上线到微信 说明
════════════════════════════════════════════════════════════

这个文件夹是【纯静态】网站（已经提前渲染好，不需要服务器、不需要装环境），
把它传到任何一个“静态网站托管”就能直接打开。

────────────── 第一步：选一个地方上传（免费）──────────────

【方案 A】Cloudflare Pages（推荐，国内一般能直接打开，网址无子路径）
  1. 打开 dash.cloudflare.com 注册/登录
  2. 左侧菜单 → Workers 和 Pages → 创建 → Pages → “上传资产”
  3. 项目名随便填，把本文件夹里所有文件（index.html、_next、两张图片等）
     拖进上传框 → 部署
  4. 完成之后给你一个 https://xxxx.pages.dev 的网址，复制它

【方案 B】GitHub Pages
  1. 注册/登录 github.com → 右上角 + → New repository
  2. 仓库名填：你的用户名.github.io（这样网址才是根路径，不会出问题）
     → 勾选 Public → Create repository
  3. Add file → Upload files → 把本文件夹所有文件拖进去 → Commit
  4. 仓库 Settings → Pages → Branch 选 main，文件夹选 /(root) → Save
  5. 等 1~2 分钟，网址就是：https://你的用户名.github.io
     （如果仓库名不是 xxx.github.io 而是别的名字，网址会带 /仓库名 子路径，
      本网页图片是绝对路径，子路径下会显示不出图 —— 所以用上面的命名最稳）

────────────── 第二步：先自己用手机测一下 ──────────────
先不要用微信，用手机浏览器（Safari/Chrome）打开那个网址：
  · 能打开、有星星背景和图片
  · 点“打开这封信”能弹出信、能关掉
没问题了再进行第三步。

────────────── 第三步：发微信给她 ──────────────
  · 直接把网址复制、粘贴发到微信聊天里，她点一下就能在微信里打开。
  · 如果微信弹出“已停止访问该网页”或让她“复制链接到浏览器打开”：
     把网址用“二维码生成器”生成一张二维码图片（网上随便搜一个，
     或小程序里搜“二维码生成”），把图片发给她 →
     她长按图片 → “识别图中二维码” → 就能直接在微信里打开（常规绕过办法）。
  · 如果她那边打开特别慢：主页那张图比较大(2.6MB)，4G 下可能要等几秒，
     属正常；不影响打开。

────────────── 注意事项 ──────────────
  · 网站必须先“上线”（有公网网址）才能在微信打开；只在自己电脑上跑，
    她那边是打不开的。
  · 别用 *.workers.dev（大陆被墙）；Vercel/Netlify 在国内时好时坏；
    GitHub Pages 和 Cloudflare Pages 相对稳。
  · 如果这套静态文件以后改了内容：重新渲染一遍再上传即可
    （在 love-for-wang 目录跑 npm run build 后，重新抓取 /
     页面的 HTML 替换这里的 index.html，_next 整个文件夹也一起替换）。
